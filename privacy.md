# Autoclip - Privacy Policy

Last updated: November 21, 2026

## 1. Who we are
Autoclip is a personal desktop tool operated by Imaginary Flame ("the Owner"). Contact: imaginaryflamepro@gmail.com

## 2. Data we access
When the Owner authorizes Autoclip through TikTok Login Kit, the app receives an access token and a refresh token for the Owner's own TikTok account, and basic profile information (scope user.info.basic).

## 3. How data is used
The tokens are used only to upload the Owner's video files to the Owner's TikTok inbox as drafts (scope video.upload). No other use is made of this data.

## 4. Storage and sharing
Tokens are stored only in a local file on the Owner's own computer. They are not sent to any server other than TikTok's, and are never sold, shared or disclosed to third parties. Autoclip has no server, no database and no analytics, and does not collect data about any other TikTok user.

## 5. Retention and deletion
Tokens are kept until the Owner revokes the app's access in TikTok settings (Settings and privacy > Security and permissions > Apps and services) or deletes the local token file. Revoking access ends all data access immediately.

## 6. Children
Autoclip is not intended for use by anyone other than the Owner and collects no data from children.

## 7. Changes
This policy may be updated. The latest version is always published at this page.
